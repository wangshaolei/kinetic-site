本機姿勢辨識是怎麼運作的

每一幀畫面都由 Google ML Kit 在手機上分析，轉換成身體關鍵點的位置後立即丟棄。KINETIC 用這些關鍵點算出關節角度來計數。不錄影、不上傳，訓練紀錄也只留在手機上。

每一幀畫面經歷了什麼

  1. 相機拍下一幀。手機還在處理上一幀時送來的畫面直接略過、不排隊，所以計數不會落後於你的動作。
  2. ML Kit 找到你的身體。Google ML Kit 的姿勢辨識模型內建在 App 裡，會找出肩、肘、髖、膝、踝等 33 個身體關鍵點。
  3. 畫面被丟棄。只留下關鍵點的位置（一串數字），畫面本身從不寫入儲存空間。
  4. 計算關節角度。例如深蹲，KINETIC 測量膝蓋處大腿和小腿的夾角。位置會做平滑處理，減少抖動。
  5. 計數。角度越過完成門檻、再回到起始姿勢，計數 +1。

哪些資料會離開手機

資料會離開手機嗎
相機畫面和圖片永不
訓練紀錄永不。依帳號只儲存在這支手機上
Google 帳號的暱稱、電子郵件、頭像不會傳到我們的伺服器。登入後儲存在這支手機上
匿名使用統計和當機報告（Google Firebase）會，除非在設定中關閉。不含畫面、帳號或電子郵件
ML Kit 匿名使用統計（模型版本、執行時間）會，由 ML Kit 傳給 Google。從不包含畫面

辨識在手機上完成，所以沒有網路也能計數。

完整說明請見隱私權政策。

Android 免費下載，畫面從不離開手機。
