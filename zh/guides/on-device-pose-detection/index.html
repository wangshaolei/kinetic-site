本机姿态识别是怎么工作的

每一帧画面都由 Google ML Kit 在手机上分析，转换成身体关键点的位置后立即丢弃。KINETIC 用这些关键点算出关节角度来计数。不录像、不上传，训练记录也只留在手机上。

每一帧画面经历了什么

  1. 摄像头拍下一帧。手机还在处理上一帧时送来的画面直接跳过、不排队，所以计数不会落后于你的动作。
  2. ML Kit 找到你的身体。Google ML Kit 的姿态识别模型内置在 App 里，会找出肩、肘、髋、膝、踝等 33 个身体关键点。
  3. 画面被丢弃。只留下关键点的位置（一串数字），画面本身从不写入存储。
  4. 计算关节角度。比如深蹲，KINETIC 测量膝盖处大腿和小腿的夹角。位置会做平滑处理，减少抖动。
  5. 计数。角度越过完成阈值、再回到起始姿势，计数 +1。

哪些数据会离开手机

数据会离开手机吗
摄像头画面和图片永不
训练记录永不。按账号只保存在这台手机上
Google 账号的昵称、邮箱、头像不会发到我们的服务器。登录后保存在这台手机上
匿名使用统计和崩溃报告（Google Firebase）会，除非在设置里关闭。不含画面、账号或邮箱
ML Kit 匿名使用统计（模型版本、运行时间）会，由 ML Kit 发给 Google。从不包含画面

识别在手机上完成，所以没有网络也能计数。
